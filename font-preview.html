Same hero, same animation — only the heading + badge font changes.

Heads up: of the 8 fonts you added, 6 (all the "ML-TT-*" ones — Anakha, Bhavana, Gauri Heavy, Kanika, Ravivarma, Vinay) turned out to be legacy pre-Unicode Malayalam fonts. They map ordinary Latin keystrokes directly to Malayalam-shaped glyphs (an old font format from before Unicode Malayalam existed), so they don't have any mapping for real Unicode Malayalam text like this site uses — applying them just silently falls back to the default font. Only Dyuthi and Nupuram Calligraphy are genuine Unicode fonts. If you want the "ML-TT" look specifically, you'd need Unicode versions of those same typefaces.

I also sourced 6 more genuine Unicode Malayalam fonts from Google Fonts and verified each one directly (checked their actual glyph tables for full Malayalam coverage, not just the family name) — Baloo Chettan 2, Manjari, Chilanka, Gayathri, Anek Malayalam, and Noto Serif Malayalam — added below alongside your two working picks.
